# 香港家庭遊 2027

Static itinerary page for the family trip to Hong Kong (13–17 Feb 2027).

- `index.html` — the whole site: inline CSS + vanilla JS, no build step.
- `images/` — photos from Wikimedia Commons (credits are listed at the bottom of the page).

Hosted on Vercel (project `hk-family-2027`), deployed by uploading this folder as-is.

To edit the itinerary, change the `DAYS` data near the top of the `<script>` in `index.html`.
